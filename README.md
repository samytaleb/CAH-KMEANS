# Hierarchical clustering and K-means

Exploratory unsupervised-learning work comparing **CAH** (*classification ascendante hiérarchique*, hierarchical agglomerative clustering) and **K-means**.

## Files

- [`cah_kmeans_classification.ipynb`](cah_kmeans_classification.ipynb) — analysis notebook
- [`AnaDo_JeuDonnees_TemperatFrance.xlsx`](AnaDo_JeuDonnees_TemperatFrance.xlsx) — temperature dataset used in the project

## Explore the analysis

Open the notebook in JupyterLab or VS Code and run the cells in order after installing the Python libraries imported by the notebook. Keep the Excel file next to the notebook, and adapt any absolute file paths to your environment.

This repository is primarily a reproducible analysis, not a packaged application. See the notebook for the methodology, figures, and interpretation.
